Latest Project

Industrial HMI Simulation

August 2026

I developed a desktop industrial HMI in C# using WPF and OPC UA to simulate a pharmaceutical bottle filling machine. The application connects to a local OPC UA server, reads live machine state and analog values, and presents them in a clear operator interface. I implemented core control actions such as start, stop, reset, and emergency stop, while organizing the solution with a MVVM-friendly structure to keep the UI, services, models, and view models separated. This project reflects my interest in industrial automation and human-machine interfaces: it combines real-time monitoring, operator interaction, and reliable communication with industrial devices. It also helped me strengthen my understanding of industrial protocols, software architecture for embedded-like systems, and the design of scalable desktop applications for control environments. The solution is structured around a WPF client for the HMI, an OPC UA communication layer, and a simulated industrial environment, which makes it a solid foundation for future extensions in factory automation and machine monitoring.

On Observability at Scale

Correlating traces, logs and metrics across a distributed system sounds simple until every service names things differently. Most of the real work on the Dassault Systèmes platform was schema and naming discipline, not the tracing tool itself.

Where Software Meets the Shop Floor

Moving from cloud-native distributed systems to SCADA and PLC programming at MCE Automation has been a useful reset: IT assumes the network is unreliable, OT assumes it barely exists. Designing for both means questioning fewer assumptions.
